# Контент-фабрика @icon___witch

Полина присылает видео боту в Telegram. Фабрика вырезает паузы, оговорки и неудачные дубли, добавляет зумы, картинки по ключевым словам, субтитры по словам, плашку, заголовок, финальную карточку, обложку и подпись. Готовый ролик приходит на согласование, а после одобрения выходит в Instagram по расписанию (19:00 МСК).

## Установка

Нужен сервер Ubuntu 22.04/24.04 в Нидерландах (Timeweb Cloud, от 2 ГБ памяти). Сначала укажите адрес репозитория в `REPO` внутри `install.sh`, затем запустите на сервере:

```
curl -fsSL https://raw.githubusercontent.com/atarverum/content-factory/main/install.sh | sudo bash
```

Установщик спросит токен бота и, по желанию, ключ Claude API и api_id/api_hash (они нужны для видео больше 20 МБ). В конце он покажет код привязки и адрес для настроек Meta.

## Команды бота

/start КОД · /invite · /plan · /stats · /style · /pause · /resume · /meta ID СЕКРЕТ · /instagram

## Устройство

- `factory/transcribe.py` распознаёт речь с таймингом каждого слова (faster-whisper).
- `factory/edit.py` монтирует ролик (ffmpeg): склейки, зумы, картинки, субтитры, звук, обложка.
- `factory/captions.py` пишет заголовок, подпись и хештеги и разбирает правки. Работает на Claude API с серверной запасной моделью, а без ключа подставляет шаблон.
- `factory/instagram.py` публикует Reels через официальный API, продлевает токен и собирает статистику.
- `factory/bot.py` отвечает за Telegram-бота, очередь, расписание и веб-адреса для Instagram.
- `factory/assets/triggers.json` задаёт картинки, которые появляются на ключевых словах (порядок задаёт приоритет).
- `factory/assets/music/` — сюда можно положить mp3, тогда музыка будет тихо подкладываться под голос.

Ручной монтаж без бота: `python -m factory.run видео.mp4 --style night --title "Заголовок"`.
