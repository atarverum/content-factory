# Монтаж на Маке через Claude Code и CapCut

Второй способ работы фабрики: без сервера и без загрузки видео в интернет. Claude Code на Маке сам
расшифровывает ролик, пишет монтажный лист в стиле Полины, собирает готовый mp4 и кладёт тот же монтаж
черновиком в CapCut, где любую мелочь можно поправить руками.

## Установка

1. Скачайте архив библиотеки (картинки, звуки, эффекты) в «Загрузки», если он у вас есть.
2. Откройте Терминал и выполните:

```
curl -fsSL https://raw.githubusercontent.com/atarverum/content-factory/main/mac/install.sh | bash
```

Установщик ставит ffmpeg, Python, Node, распознавание речи (faster-whisper) и сборщик черновиков
[capcut-cli](https://github.com/renezander030/capcut-cli), создаёт папку `~/Movies/Фабрика` и подключает
навык `montazh-polina` к Claude Code (`~/.claude/skills`). Повторный запуск обновляет всё до свежей версии.

## Как пользоваться

1. Положите видео в `Фильмы → Фабрика → Входящие`.
2. Закройте CapCut.
3. В приложении Claude откройте вкладку Code, выберите папку `Фабрика` и напишите «Монтируй».
4. Готовый ролик появится в `Готово`, черновик с тем же названием — в CapCut.
5. Правки пишите Claude обычными словами или делайте руками в CapCut.

## Что внутри

- `skill/SKILL.md` — инструкция для Claude: порядок работы и формат монтажного листа `edl.json`.
- `skill/polina.md` — паспорт стиля Полины.
- `skill/scripts/transcribe.py` — расшифровка по словам (`words.json`, `script.txt`).
- `skill/scripts/build.py` — сборка по `edl.json`: mp4 и черновик CapCut из одного и того же листа.
- `skill/scripts/sheet.py` — лист кадров для самопроверки.

Проверенные версии CapCut для черновиков — 8.x–9.x; CapCut 10 может не открыть черновик, тогда остаётся mp4.
